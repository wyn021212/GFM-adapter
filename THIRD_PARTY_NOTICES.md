# Third-party components

`cores/backbones/` contains the model implementations supplied with the BRIDGE, MDGFM, SAMGPT, GRAVER, and GCOPE experiment code. Imports and local resource paths have been adapted to this package. Original license texts available in the supplied materials are retained in `licenses/`.

The datasets retain their original source distribution files. No new license is granted for third-party code, data, or model weights by this package.

GraphGlue was used as a reference for directory organization. Its model implementation and illustrations are not included.
